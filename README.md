Cryptocurrency Market Analysis & Interactive Excel Dashboard

Internship Project – Elevance Skills

Project Overview

This project focuses on analysing cryptocurrency market data and creating an interactive Excel dashboard to understand cryptocurrency price movements, market trends, and investment insights.

The project was completed as part of my internship at Elevance Skills. It involves collecting cryptocurrency market data, organising datasets, performing data analysis, creating PivotTables, applying slicers, and developing interactive charts and dashboards using Microsoft Excel.

The project analyses approximately 200 cryptocurrencies using different price and percentage-change indicators.

---

Objectives of the Project

The main objectives of this project are:

- To analyse cryptocurrency market data.
- To understand cryptocurrency price fluctuations.
- To compare short-term and weekly price movements.
- To identify cryptocurrencies with different price ranges.
- To analyse cryptocurrency liquidity using trading volume.
- To create interactive dashboards using Excel.
- To present meaningful insights through charts, tables, KPIs, and slicers.

---

Dataset Description

The project uses cryptocurrency market data containing approximately 200 cryptocurrencies.

The dataset includes the following columns:

Column| Description
Name| Name of the cryptocurrency
Symbol| Cryptocurrency trading symbol
Price| Current cryptocurrency price
1h %| Percentage price change in the last 1 hour
24h %| Percentage price change in the last 24 hours
7d %| Percentage price change in the last 7 days

Project Analysis

The project is divided into four major analytical sections.

1. Historical Price Change Insights

This analysis focuses on understanding cryptocurrency price movements over different time periods.

Key activities:

- Analysed 1-hour, 24-hour, and 7-day percentage changes.
- Applied price filters to identify cryptocurrencies within the selected budget range.
- Compared cryptocurrency price movements.
- Created charts to display price-change insights.
- Identified the top 10 cryptocurrencies based on 1-hour percentage change.

2. Top 5 Crypto Liquidity Analysis

This section focuses on analysing cryptocurrency liquidity using 24-hour trading volume.

Key activities:

- Analysed cryptocurrency trading volume.
- Identified the top 5 cryptocurrencies based on trading volume.
- Grouped the remaining cryptocurrencies under "Others".
- Created a pie chart to represent the trading-volume distribution.
- Used price-range slicers to make the analysis interactive.

3. Price Change Comparison Analysis

This analysis compares cryptocurrency prices and their percentage changes over a short period.

Key activities:

- Analysed current cryptocurrency prices.
- Calculated previous prices using the 1-hour percentage change.
- Identified the top 10 cryptocurrencies based on price change.
- Created comparison tables and charts.
- Used price-based slicers to filter the results.

4. Low Budget Investment Insights

This section focuses on identifying cryptocurrencies with the lowest average percentage downfall.

Key activities:

- Analysed cryptocurrency prices and percentage changes.
- Calculated the average downfall percentage.
- Identified cryptocurrencies with the least average downfall.
- Created KPI indicators to display important information.
- Included cryptocurrency name, symbol, price, average downfall percentage, and total number of coins in the selected price range.
- Added interactive price-range slicers.
