About the Project

Understanding cryptocurrency market data through structured analysis and interactive Excel dashboards.

This project is based on cryptocurrency market data containing information about approximately 200 cryptocurrencies.

The dataset includes cryptocurrency names, symbols, current prices, 1-hour percentage changes, 24-hour percentage changes, and 7-day percentage changes.

Microsoft Excel is used to organize, analyze, compare, and visualize the data through PivotTables, charts, formulas, filters, and slicers.

The main purpose is to understand cryptocurrency price movements, trading liquidity, and possible opportunities in different price ranges.

Project Analysis

The project consists of four major cryptocurrency data analysis topics.

📈

01. Historical Price Change Insights

This analysis studies cryptocurrency price movements over different time periods.

  • Analyzes 1-hour, 24-hour and 7-day changes.
  • Identifies cryptocurrency price movements.
  • Filters coins within the $0–$5 price range.
  • Compares 7-day and 24-hour changes for the top 10 coins ranked by 1-hour change.
💧

02. Top 5 Crypto Liquidity Analysis

This analysis identifies the five cryptocurrencies with the highest 24-hour trading volume.

  • Uses 24-hour trading volume.
  • Identifies the top five cryptocurrencies.
  • Groups the remaining cryptocurrencies as Others.
  • Uses a pie chart for visualization.
  • Includes price-range slicers.
⚖️

03. Price Change Comparison Analysis

This analysis compares current prices with estimated previous prices using 1-hour changes.

  • Calculates previous 1-hour prices.
  • Identifies the top 10 cryptocurrencies by price change.
  • Compares price movements.
  • Uses price-range slicers.
  • Displays results using charts and tables.
💰

04. Low Budget Investment Insights

This analysis focuses on cryptocurrency prices and average percentage downfall.

  • Identifies the coin with the least average downfall.
  • Calculates average downfall percentage.
  • Displays coin name, symbol and price.
  • Shows total coins in the selected range.
  • Uses five price-range slicer categories.
